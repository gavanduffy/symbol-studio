# Symbol Studio

A browser-based symbol explorer with searchable open-source icons, custom color and stroke controls, subtle animation presets, saved favorites, and custom-size SVG/PNG export.

## Assets and licensing

- The symbol catalog is generated from [Lucide](https://lucide.dev), licensed under ISC.
- `public/background_gradient.png` is a user-supplied visual asset.
- The uploaded custom font files are deliberately not included because their local metadata did not provide a verifiable redistribution license. Apple SF Symbols are not included.

## Run locally

```bash
npm install
npm run dev
```
